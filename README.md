# 霖林小屋 · Linlin Cabin

一座藏在森林深处的小木屋，屋前空地种满向日葵，树上有松鼠、小鸟和猫头鹰，花丛间蝴蝶与蜜蜂往来。支持五种天气/时段实时切换，全程序化建模，无任何外部素材。

## 在线体验

https://yjj0339.github.io/linlin-cabin/

手机浏览器打开后可「添加到主屏幕」，以全屏应用方式运行，并支持离线访问（Service Worker 缓存）。

## 场景内容

- **小屋**：石砌地基、木板墙、木瓦屋顶、阁楼圆窗、门牌「霖林小屋」、双灯笼、窗台花箱、石阶门廊、柴堆与木桶
- **向日葵田**：78 株程序化向日葵，花盘朝向太阳，茎叶随风轻摆
- **植被**：近景大树 4 棵、远景森林 130 棵、1900 丛杂草（着色器风动）、野花、蘑菇、石块、灌木
- **动物**：树干上的松鼠（尾巴摆动）、枝头三只小鸟（转头/跳跃/振翅）、猫头鹰（眨眼）、地上兔子
- **昆虫**：6 只蝴蝶（翅膀扇动 + 曲线飞行）、9 只蜜蜂（高频振翅）
- **天气**：晴 / 雾 / 黄昏 / 夜 / 雨，光照、雾、天空、云、窗光、萤火虫、雨丝全参数平滑过渡

## 交互

- 单指拖动 / 鼠标拖动：环绕旋转
- 双指捏合 / 滚轮：缩放
- 底部胶囊按钮：切换天气
- 静止 6 秒后自动缓慢旋转

## 技术

- Three.js r158（本地化，无 CDN 依赖）
- 全部几何体与纹理程序化生成（Canvas 绘制木纹/树皮/瓦片/石纹/草叶/花盘/门牌）
- InstancedMesh 批量渲染（向日葵 5 个 draw call 渲染 78 株、草 2 个、森林 4 个）
- 着色器实现风动草叶、烟雾、雨滴、天空渐变
- 移动端自适应：像素比限制、阴影贴图降级、帧率不足时自动降档
